# Safra Voyages
Mini-projet Dev. Web côté client (TI1, 2026-2027) : site d'une agence de voyages tunisienne.

- **Pages** : accueil, destinations, offres, contact
- **Technologies** : HTML5 sémantique, CSS3 (Flexbox, Grid, variables, media queries), JavaScript (DOM, événements), PHP/MySQL (2 requêtes)
- **Interactions JS** : menu burger, mode sombre, filtre des destinations, calculateur de prix, validation du formulaire, chargement des offres
- **Ouvrir le site** : ouvrir `index.html` (les offres utilisent des données locales sans PHP). Pour la partie PHP : importer `sql/safra.sql` dans MySQL, copier le dossier dans `htdocs` (XAMPP) puis ouvrir `http://localhost/safra/`.
